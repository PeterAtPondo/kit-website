Supported surfaces and data sources

Kit lives in the tools you already use, and remembers the history you already have. Here is what Kit supports today, with a link to each tool. Anything marked in development is on the way.

Surfaces, where Kit lives

A surface is a place Kit can talk with you. Anything that speaks MCP qualifies, so new agent CLIs work the moment they appear. The Mac app detects which of these are installed and connects them for you.

  • Claude Code
    Anthropic's agentic coding tool in the terminal.
    claude.com/claude-code ↗
  • Codex
    OpenAI's coding agent CLI.
    developers.openai.com ↗
  • Cursor
    The AI code editor.
    cursor.com ↗
  • VS Code
    Visual Studio Code with MCP support.
    code.visualstudio.com ↗
  • Gemini CLI
    Google's open-source terminal agent.
    github.com/google-gemini ↗
  • Qwen Code
    Alibaba's open-source coding CLI.
    github.com/QwenLM ↗
  • Ollama Code
    Run local models, and point Kit at them.
    ollama.com ↗
  • CodeWhale
    Agent CLI. Chats captured by polling its local history.
    github.com/Hmbown ↗
  • Antigravity
    Google's Antigravity. Chats captured by polling.
    antigravity.google ↗
  • OpenCode
    Open-source coding agent. Sessions captured by polling; its history imports too. OpenCode Zen is also a model provider your Kit can think with.
    opencode.ai ↗
  • Claude desktopwith Claude Code
    Kit's tools reach the desktop app through Claude Code's registration; the app detects it and says so. Capturing its chats is in development.
    claude.com/download ↗
  • AnythingLLMtalk only
    Talk to Kit over MCP. Capturing its chats is in development.
    anythingllm.com ↗

Data sources, what Kit remembers

A data source is anything that feeds Kit's memory. Kit captures your connected coding tools live as you work, imports the history those tools already hold, and brings in a ChatGPT export and a connected mailbox from the app. The rest below is on the way. Nothing leaves your Mac unless you send it.

Captured live

Your connected coding and agent tools, captured as you work: Claude Code, Codex, Cursor, VS Code, Gemini CLI, Qwen Code, Ollama Code, CodeWhale, Antigravity, and OpenCode (the surfaces above).

Imported from the applive

The app finds these on your Mac, asks before it reads them, and folds them into memory with the date each thing actually happened.

  • Coding tool history
    Claude Code, Codex, Cursor, VS Code, CodeWhale, Antigravity and OpenCode transcripts already on your machine, imported at setup or later from Data Sources.
    local files
  • ChatGPT export
    Your exported ChatGPT conversations. Put the export's conversations.json in Desktop, Downloads or Documents and the app offers it.
    chatgpt.com ↗
  • Mailbox
    Connect a mailbox in Settings and your Kit reads it: mail from you is met as you, mail that needs your call parks for your decision, and you can tell it whose address is whose.
    IMAP

Imported historyin development

Kit has importers for these, but they are not wired into the app yet. Because the local app can ask for your permission, it opens an easier path to bring them in, and to watch folders for new files, which is what we are building next. Listed here so you can see where Kit is heading.

  • Claude export
    Your exported Claude conversations.
    claude.ai ↗
  • Documents
    PDFs, Word documents, and images you bring in.
    local files
  • Strava
    Your activity history from a Strava export.
    strava.com ↗
  • Mail history
    Bulk import of the threads already in your mailbox, so past decisions surface as dated clusters. The live mailbox above reads what arrives from now on.
    IMAP
  • Calendar (CalDAV)
    Your events, for time and context, over CalDAV.
    calendar.google.com ↗
  • Telegramlive
    Chat with Kit on Telegram, approve runs, and get notifications, live now. Importing past chats is in development.
    telegram.org ↗
