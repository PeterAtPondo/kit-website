Supported surfaces and data sources

Kit lives in the tools you already use, and remembers the history you already have. Here is what Kit supports today, with a link to each tool. Items marked in development are not available through the app yet. Choose a trial for your work.

Check the missing connection first

Direct Figma sync and automatic capture from browser chats are not available. A chat export, document or manual note can support a trial, but has to be kept current. Telegram is available after Mac setup; it does not remove the installation or model-connection step. Team deployment and enterprise governance are still in development.

Data sources, what Kit remembers

A data source is anything that feeds Kit's memory. Kit captures your connected coding tools live as you work, imports the history those tools already hold, and brings in a ChatGPT export and a connected mailbox from the app. Selected material can be sent to the model you choose for extraction and consolidation. Local storage does not mean a hosted model never sees your data. Check the data paths before importing company or client information.

Captured live

Your connected coding and agent tools, captured as you work: Claude Code, Codex, Cursor, VS Code, Gemini CLI, Qwen Code, Ollama Code, CodeWhale, Antigravity, and OpenCode (the surfaces above).

Imported from the applive

The app finds these on your Mac, asks before it reads them, and folds them into memory with the date each thing actually happened.

  • Coding tool history
    Claude Code, Codex, Cursor, VS Code, CodeWhale, Antigravity and OpenCode transcripts already on your machine, imported at setup or later from Data Sources.
    local files
  • ChatGPT export
    Request an export from ChatGPT, then use Upload archive under Data sources → Web chats. The file picker accepts the export; Kit does not have direct access to your ChatGPT account.
    chatgpt.com ↗
  • Mailbox
    Connect a mailbox in Settings and your Kit reads it: mail from you is met as you, mail that needs your call parks for your decision, and you can tell it whose address is whose.
    IMAP
  • Claude export
    Request your archive from Claude, then choose Upload archive under Data sources → Web chats. New exports can be added later; this is not live capture.
    claude.ai ↗
  • Documents
    Use Sources → Documents → Add Documents, or include a folder. Check the extracted content and derived memories: importing a file does not establish faithful visual understanding.
    local files
  • Obsidian and included folders
    Select an existing vault or folder, then check its import status and source records. Keeping files in sync and recalling their meaning are separate checks.
    local files
